## Профиль пользователя

Показывает текущие музыкальные роли пользователя по которым формируется список [/spec/participate/index.md](/spec/participate/index.md)
Музыкальные роли можно редактировать исходя из доступных [/spec/suggest/default-roles.md](/spec/suggest/default-roles.md) т.е. можно деактивировать одни и активировать другие.
