## Доступные роли к выбору:
Главная гитара
Ритм гитара
ударные, 
клавиши, 
бас-гитара, 
я пою, 
другое

Роль «другое» — необязательное дополнение на случай, если перечисленных музыкальных ролей недостаточно. Она не добавляется в состав песни по умолчанию; автор может добавить ее по необходимости. Наличие участника на этой роли не требуется для зеленого статуса.

Клавиши не входят в исходную формулу зеленого статуса и не являются обязательными для его получения. Это не исключает их из списка ролей песни по умолчанию. Актуальные формулы описаны в [статусах песен](/spec/participate/statuses.md).
