## Знакомство

После первой авторизации, при которой Telegram передал username, пользователь попадает на экран знакомства. Пока username отсутствует, вместо знакомства показывается экран восстановления доступа по правилам [авторизации](/spec/telegram-auth-spec.md#требование-приложения-к-telegram-username). Знакомство показывается пользователю только один раз и может быть закрыто. После завершения или закрытия оно не появляется при следующих входах; этот выбор сохраняется для пользователя.
Экран содержит список шагов, на каждом шаге вопрос и варианты ответов.
Шаги в приложении будут без нумерации, здесь я буду использовать нумерацию для упрощения навигации по шагам.

Нише описание шагов:
1) Заголовок: Добро пожаловать! 
Текст: Цель нашего сообщества предложить как можно большему количеству людей музыкально себя проявлять. 
Вопрос: Скажи было бы тебе интересно выступить в составе таких де творческих энтузиастов?
Варианты ответа: да / нет

2.1) Если пользователь ответил в первом шаге да:
Вопрос: Супер. Скажи на каких инструментах ты играешь?
Варианты ответа: [roles.md](/spec/roles.md) (можно выбрать несколько)
Кнопка: дальше (кнопка активна, т.е. можно ничего не выбрать) и переход к шагу 2.2
Если все-же что-то было выбрано музыкальные роли добавляются в профиль пользователя [/spec/profile/index.md](/spec/profile/index.md)
Описание: Можно выбрать несколько вариантов, каждый из вариантов выглядит как пил/чип c иконкой и текстом, которая меняет свой вариант с просто обводка, на залитый цветом.
У каждого "интрумента" свой цвет. Набор цветов нужно предварительно подготовить в палитре темы.
Иконки брать из какой-нибудь библиотеки иконок которая предоставляет такой набор. Иконки должны быть в одном стиле.

2.2) Если пользователь ответил в первом шаге нет:
Вопрос: Ок, без проблем. Может ты хочешь предложить песню к исполнению на следующий джем?
Варианты ответа да / нет.

Если пользователь перешел с шага 2.1 то вопрос меняется
Хочешь ли ты предложить песню к исполнению на следующий джем?
Варианты ответа да / нет.

Если да то появляется следующий шаг
2.3) Предложить песню. Описание тут
[spec/suggest/index.md](/spec/suggest/index.md)
По нажатию предложенная песня добавляется в общий список песен на ближайший джем. Пользователь переходит к 2.4
В разделе "активность" у пользователя в подразделе "предложил" появится элемент списка с названием песни и индикатором ее статуса: белый, желтый, зеленый или фиолетовый. Статусы описаны в [статусах песен](/spec/participate/statuses.md).
Кнопка "я передумал": всегда доступна – переход на главную страницу приложения [main-page.md](/spec/home)

2.4) Хочешь предложить еще?
Кнопки:
Предложить еще – переход к шагу 2.3
Не, хватит – переход на главную страницу приложения [main-page.md](/spec/home)
